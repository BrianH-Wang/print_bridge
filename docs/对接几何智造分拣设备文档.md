# 对接几何智造分拣设备文档

## 0. 通用说明

| 项目         | 说明                     |
| ------------ | ------------------------ |
| 服务地址     | `http://127.0.0.1:13213` |
| 请求方式     | `POST`                   |
| Content-Type | `application/json`       |
| 字符编码     | `UTF-8`                  |
| 鉴权         | 无                       |

所有接口返回结构一致：

| 返回字段 | 字段名称 | 数据类型         | 必选 | 描述                                      |
| -------- | -------- | ---------------- | ---- | ----------------------------------------- |
| success  | 是否成功 | 布尔值 *boolean* | 是   | `true` 表示业务处理成功，`false` 表示失败 |
| code     | 响应代码 | 数字 *int*       | 是   | 200 表示成功，其余见各接口错误码表        |
| msg      | 提示信息 | 字符串 *string*  | 是   | 响应提示信息，失败时为具体原因            |
| data     | 数据     | 对象 *Object*    | 否   | 业务数据对象，`null` 表示无数据           |

## 1. 数据推送接口

### 1.1. 接口信息

| 项目     | 说明                               |
| -------- | ---------------------------------- |
| 接口地址 | `http://127.0.0.1:13213/callback`  |
| 用途     | 推送过机包裹的条码、重量、体积数据 |

其余同「通用说明」。

### 1.2. 请求入参

| 入参字段 | 字段名称 | 数据类型                         | 必选 | 描述                         |
| -------- | -------- | -------------------------------- | ---- | ---------------------------- |
| code     | 编码     | 字符串 *string*                  | 是   | 对应条码/二维码的值          |
| weight   | 重量     | 字符串 *string*                  | 是   | 单位：公斤（kg），小数点两位 |
| height   | 高度     | 数字 *decimal* / 字符串 *string* | 是   | 单位：厘米（cm），小数点两位 |
| width    | 宽度     | 数字 *decimal* / 字符串 *string* | 是   | 单位：厘米（cm），小数点两位 |
| length   | 长度     | 数字 *decimal* / 字符串 *string* | 是   | 单位：厘米（cm），小数点两位 |

> 本接口不接收图片，图片请通过第 2 章「上传接口」以相同的 `code` 单独上传。

### 1.3. 返回字段

同「通用说明」，`data` 为分拣结果对象。

#### 1.3.1. data 对象字段

| 字段         | 字段名称        | 数据类型                 | 必选 | 描述                                 |
| ------------ | --------------- | ------------------------ | ---- | ------------------------------------ |
| route        | 分拣代码        | 字符串 *string*          | 否   | 分拣目标格口代码，无分拣结果时不返回 |
| totalCount   | 总件数          | 数字 *int*               | 否   | —                                    |
| currentCount | 当前过机件数    | 数字 *int*               | 否   | —                                    |
| mainOrderNo  | 主单号          | 字符串 *string*          | 否   | —                                    |
| pdfBase64    | 打印标签PDF文件 | *base64*（无需格式前缀） | 否   | —                                    |

#### 1.3.2. 错误码表

| code | 含义       | 常见原因       |
| ---- | ---------- | -------------- |
| 200  | 成功       | —              |
| 404  | 接口异常   | 服务器接口错误 |
| 500  | 服务器错误 | 服务器逻辑错误 |

### 1.4. 请求示例

#### 1.4.1. 请求入参示例

```json
{
  "code": "CCSL2026083100123",
  "weight": "12.50",
  "height": "35.20",
  "width": "28.00",
  "length": "40.75"
}
```

#### 1.4.2. curl

```bash
curl -X POST http://127.0.0.1:13213/callback \
  -H "Content-Type: application/json" \
  -d '{
    "code": "CCSL2026083100123",
    "weight": "12.50",
    "height": "35.20",
    "width": "28.00",
    "length": "40.75"
  }'
```

#### 1.4.3. Windows PowerShell

```powershell
$body = @{
  code   = "CCSL2026083100123"
  weight = "12.50"
  height = "35.20"
  width  = "28.00"
  length = "40.75"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:13213/callback" `
  -Method Post -ContentType "application/json; charset=utf-8" -Body $body
```

### 1.5. 返回示例

#### 1.5.1. 成功示例

```json
{
  "success": true,
  "code": 200,
  "msg": "操作成功",
  "data": {
    "route": "A"
  }
}
```

#### 1.5.2. 失败示例

接口错误：

```json
{
  "success": false,
  "code": 404,
  "msg": "服务器接口错误",
  "data": null
}
```

逻辑错误：

```json
{
  "success": false,
  "code": 500,
  "msg": "服务器逻辑错误",
  "data": null
}
```

## 2. 上传接口

### 2.1. 接口信息

| 项目     | 说明                            |
| -------- | ------------------------------- |
| 接口地址 | `http://127.0.0.1:13213/upload` |
| 用途     | 上传条码对应的图片文件          |

其余同「通用说明」。

### 2.2. 请求入参

| 入参字段 | 字段名称 | 数据类型                 | 必选 | 描述                          |
| -------- | -------- | ------------------------ | ---- | ----------------------------- |
| code     | 编码     | 字符串 *string*          | 是   | 对应条码/二维码的值           |
| file     | 图片     | *base64*（无需格式前缀） | 是   | 仅支持 jpg、png、pdf，最大 2M |

### 2.3. 返回字段

同「通用说明」，`data` 固定为 `null`。

#### 2.3.1. 错误码表

| code | 含义         | 常见原因                                             |
| ---- | ------------ | ---------------------------------------------------- |
| 200  | 成功         | —                                                    |
| 404  | 接口异常     | 服务器接口错误                                       |
| 413  | 文件过大     | base64 解码后超过 2M                                 |
| 415  | 文件解析失败 | `file` 为空、base64 无法解码、格式不属于 jpg/png/pdf |

### 2.4. 请求示例

#### 2.4.1. 请求入参示例

```json
{
  "code": "CCSL2026083100123",
  "file": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg=="
}
```

#### 2.4.2. curl

```bash
curl -X POST http://127.0.0.1:13213/upload \
  -H "Content-Type: application/json" \
  -d '{
    "code": "CCSL2026083100123",
    "file": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg=="
  }'
```

#### 2.4.3. Windows PowerShell

```powershell
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes(".\label.jpg"))

$body = @{
  code = "CCSL2026083100123"
  file = $b64
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:13213/upload" `
  -Method Post -ContentType "application/json; charset=utf-8" -Body $body
```

### 2.5. 返回示例

#### 2.5.1. 成功示例

```json
{
  "success": true,
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

#### 2.5.2. 失败示例

文件过大：

```json
{
  "success": false,
  "code": 413,
  "msg": "文件超过 2M 限制",
  "data": null
}
```

文件解析失败：

```json
{
  "success": false,
  "code": 415,
  "msg": "文件解析失败，请检查 base64 内容与文件格式",
  "data": null
}
```

接口错误：

```json
{
  "success": false,
  "code": 404,
  "msg": "服务器接口错误",
  "data": null
}
```
